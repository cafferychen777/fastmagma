# Provenance

The initial extraction on 2026-09-24 copied the original implementation from
`EdgeMap/pilot_interface_20260924/fastmagma`. The source project was not modified.
The original core's SHA-256 is recorded in CHANGELOG.md after snapshot verification.

The standalone package subsequently received numerical corrections and engineering
changes. It is no longer byte-identical to that research script. `docs/ALGORITHM.md`
is the single current algorithm description; superseded development claims are
not retained as competing instructions.

Included utilities originated in the same directory. Excluded materials include
experiment results, project-specific gene mappings, third-party MAGMA source,
binaries, archives, and manuals. The original MIT notice is preserved. Chen Yang
is listed as maintainer; no new scientific authorship roster is inferred.

Version 0.1.0 is the first local standalone package version, not evidence of a
registry release. A repository URL must be added only after the actual standalone
repository has been created. The release process is documented in RELEASING.md.
